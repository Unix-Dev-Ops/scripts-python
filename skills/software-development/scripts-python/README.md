# scripts-python

Lean Hermes skill: rigid standard for long-lived Python scripts and tools.

## Contents

- `SKILL.md` — agent rules
- `templates/template_base.py` — **only** skeleton
- `references/python-conventions.md` — naming and style
- `references/authoring.md` — how to apply the rules

**Not included:** production tools, host briefs, duplicate templates, examples clone.

## Install

```bash
mkdir -p ~/.hermes/skills/software-development
cp -a scripts-python ~/.hermes/skills/software-development/
```

Load by name: `scripts-python`. Do not also copy it into a Hermes profile.
